# Asally Lab — v2

HTML・CSS・JavaScript・画像・動画・ローカルフォントを同梱した静的サイトです。ビルド作業は不要です。

## 確認方法
ZIPを解凍し、asallylab-site/index.htmlをブラウザで開いてください。動画はブラウザの設定により再生ボタンの操作が必要な場合があります。

## 今回の変更
- 元サイトの暗い背景、研究室ロゴ、細い罫線、Source Sans Proを継承。
- トップページに Bioelectricity → Physics of Life. Engineering Living Systems. を配置。
- 均一なカードをやめ、顕微鏡映像・研究装置・文章に強弱をつけた構成。
- 英語をデフォルトにし、日本語はja/以下。同じページ・節への言語切り替え。
- 各言語8ページ：トップ、研究、基礎解説、測定と操作、業績、人物、ニュース、参加・連絡。
- 解説は基礎と方法の2ページに統合。各テーマに対応する研究成果・論文へのリンクを配置。
- 元GIFの研究映像を軽量MP4へ変換。ポスター画像、再生・停止、0.5〜2倍速。画面内で一度自動再生し、手動停止後にスクロールだけで再開しません。動きを減らす設定では自動再生しません。
- 人物写真を小さくし、業績の行間・項目間を圧縮。卒業生情報とプロフィールリンクを保持。
- 33件の書誌情報を照合。詳細はBIBLIOGRAPHY_AUDIT.md。
- ページ固有のtitle/description、canonical、hreflang、構造化データ、sitemap.xmlを追加。

## 公開時
asallylab-siteフォルダの「中身」をasallylab.comのドキュメントルートに配置します。ja/、assets/、images/の階層を維持してください。404.htmlはホストの404ページに指定してください。今回は本番サイトへのアップロードは行っていません。

旧URLのHTMLは移動案内です。redirects-reference.txtの対応表をホストに応じて301リダイレクトとして設定すると、検索エンジンに統合を伝えやすくなります。表そのものはサーバー設定ではありません。旧モーダルの#work/#team/#papers/#news/#fundingもJavaScriptで移動します。

## 編集
本文は各HTML、共通デザインはassets/css/main.css、動画操作と言語リンクはassets/site.js。英語と日本語の両方を編集してください。日本語フォントは現行本文向けにサブセット化してあるため、文字追加時は必要に応じてNoto Sans JPを更新してください。data/publications.jsonは書誌確認用であり、HTMLへ自動反映する仕組みではありません。

## 権利・運用
元サイトの研究画像・人物写真・ロゴを継承。HTML5 UP Dimension由来のデザインクレジットを維持。フォントのライセンスはassets/fonts/に収録。検索流入増加は保証できません。公開後にSearch Console等で検索語と流入を測り、解説を更新することを想定しています。

## NEWSの更新（v3）
プロジェクト直下のNEWS-EDITOR-ja.mdを参照。記事の単一データソースから英語と日本語のNEWSとトップページの最新2件を再生成できます。Pages CMS用の編集設定も同梱しています。
